## 3 栈、协议族与 IPv4 / IPv6 双栈

|概念|含义|例子|
|---|---|---|
|**数据结构的栈**|数据按**后进先出**的顺序取出。|先压入 `A`，再压入 `B`，先弹出 `B`。|
|**程序的调用栈**|记录尚未结束的函数调用，按调用的逆序返回。|`main()` 调用 `f()`，`f()` 调用 `g()`，先从 `g()` 返回。|
|**协议族**|一组配合使用的协议，强调**有哪些协议**。|TCP/IP 协议族包含 TCP、UDP、IP 等。|
|**协议栈**|一组分层工作的协议，强调**各层怎么配合**。|`HTTP → TCP → IPv6 → 以太网`，分别负责请求、传输、寻址转发和链路交付。|

**IPv4 和 IPv6** 是网络层 IP 协议的两个版本。IPv4 地址是 32 位，如 `192.0.2.10`。IPv6 地址是 128 位，如 `2001:db8::10`。

**在 ZEC Console 里，堆栈按网卡配置。** 单栈启用 IPv4 或 IPv6 中的一种，双栈同时启用两种。比如，同一台实例的主网卡可以用双栈，辅助网卡可以只用 IPv4。双栈网站可以同时接待 IPv4 和 IPv6 客户端，每条普通 TCP 连接使用其中一种。
## 4 网卡-内网ip-EIP

网卡接入子网，子网给网卡分配内网 IP，EIP 绑定到这个内网 IP，提供公网入口。

|概念|简短笔记|
|---|---|
|网卡（vNIC）|实例接入网络的接口。一台实例可以有主网卡和辅助网卡。|
|子网 / 内网 IP|子网是一段地址范围，内网 IP 是这段范围里分给网卡的一个地址。|
|EIP（弹性公网 IP）|单独申请的公网地址。在 ZEC 里可以绑定到网卡上的某个内网 IPv4，换机时可以重新绑定。|

例子：一台 Web 服务器的网卡接入 `10.0.1.0/24` 子网，拿到内网 IP `10.0.1.20`。私网里的机器可以用 `10.0.1.20` 访问它。给这个内网 IP 绑定 EIP `203.0.113.20`（示例地址）后，公网用户就有了访问入口，前提是安全组放行相应端口。

### 5.2 三大运营商简称

|简称|英文全称|中文名称|说明|
|---|---|---|---|
|**CT**|China Telecom|中国电信|国内骨干网络覆盖广，国际出口资源丰富，南方省份宽带占有率较高。|
|**CU**|China Unicom|中国联通|北方省份宽带覆盖较强，国际互联线路常用于欧美方向。|

### 5.3 配置示例

|运营商|VLAN|公网 IP|出网网关|策略路由表|
|---|---|---|---|---|
|中国电信（CT）|`CT VLAN`|`CT IP`|`CT Gateway`|`table ct`|
|中国联通（CU）|`CU VLAN`|`CU IP`|`CU Gateway`|`table cu`|
|中国移动（CM）|`CM VLAN`|`CM IP`|`CM Gateway`|`table cm`|

配置策略路由时，可以按**回包的源 IP**选择对应路由表。例如，访问 `CT IP` 的连接，其回包以 `CT IP` 为源地址，经 `CT Gateway` 发出。
